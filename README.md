# Bluetooth Config Bench

Тестовая веб-страница (Web Bluetooth) для настройки устройства по BLE: статус сети, поиск Wi-Fi, смена сети/пароля, DNS. Без приложения, без интернета у устройства.

## Как открыть

Chrome или Edge (Safari на iOS не поддерживает Web Bluetooth):
`https://rusampson.github.io/BLE-static-settings-test/`

## Как пользоваться

1. Переведите устройство в режим настройки (индикатор мигает).
2. «Подключить» → выберите устройство в списке Chrome (если пусто — страница не открыта по https или устройство занято другим клиентом).
3. Введите пин-код → «Разрешить запись». Без пина страница только читает.
4. «Найти сети» → выбрать сеть, ввести пароль → «Сохранить». DNS — по желанию, «auto» = сброс.

## Примечания

- Все команды пишутся в dev-журнал устройства, боевые настройки пока не меняются.
- Один клиент за раз: вторым телефоном не перетянуть, пока первый не нажал «Отключить».
- Профиль сборки устройства — arm32, прошивка не пересобирается страницей.
